# Raw sources

Registry of every source cited by this wiki. One row = one source.
Stable public URLs are referenced; mutable or auth-walled sources get
copied into a dated bucket file.

## Format

| id | kind | ref | topics |
|---|---|---|---|

- `id` — short stable slug, used in page `sources:` frontmatter
- `kind` — `repo` | `docs` | `catalog` | `list` | `article` | `gist` | `issue` | `copy`
- `ref` — URL or `<bucket>/YYYY-MM-DD-slug.md` for copies
- `topics` — comma-separated, free-form
